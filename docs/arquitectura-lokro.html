Lokro
Marketplace de servicios locales por geolocalización
Lokro es una aplicación web que conecta a personas con profesionales de servicios cercanos — como plomeros, electricistas o tutores — usando la ubicación GPS en tiempo real.

¿Qué es Lokro?

Una app para conectar personas
con profesionales cercanos

Como un Uber, pero para servicios del hogar y el trabajo

👤

Usuario

Busca un profesional en el mapa, hace la solicitud, paga y hace seguimiento en tiempo real.

🔧

Prestador

Publica su perfil, recibe solicitudes, acepta trabajos y cobra directamente por la plataforma.

🛡️

Administrador

Gestiona usuarios, modera solicitudes y controla el funcionamiento de la plataforma.

Modelo de negocio

Lokro cobra una comisión del 10% sobre cada servicio completado al prestador. Para el usuario siempre es gratis usar la plataforma.

Tecnologías

¿Con qué está construido?

Las herramientas que hacen funcionar Lokro

⚡

Next.js — La base de la aplicación

Es el framework principal. Permite que la app funcione rápido, que Google la encuentre fácilmente y que todo el código esté en un solo lugar.

🗄️

Supabase — La base de datos

Guarda toda la información: usuarios, solicitudes, mensajes, pagos. También maneja el inicio de sesión y las notificaciones en tiempo real.

🗺️

Mapbox — Los mapas

Muestra el mapa interactivo donde aparecen los prestadores disponibles y permite hacer seguimiento GPS en tiempo real.

💳

Mercado Pago — Los pagos

Procesa los pagos de forma segura. El dinero queda retenido hasta que el usuario confirma que el trabajo se hizo bien.

📧

Resend — Los emails

Envía correos automáticos cuando se acepta una solicitud, cuando se hace el pago o cuando el servicio se completa.

☁️

Vercel — El servidor

Es donde vive la aplicación en internet. Cada vez que se sube un cambio al repositorio, Vercel lo publica automáticamente.

Arquitectura

¿Cómo está organizada la app?

Todo vive en un mismo proyecto, organizado por tipo de usuario

Tipo de arquitectura: Monolito moderno (JAMstack)

No hay un servidor separado. El frontend y el backend viven juntos en Next.js. La base de datos (Supabase) hace el trabajo pesado de seguridad y datos en tiempo real.

Las 5 zonas de la aplicación

🏠

Zona pública (Landing)

La página de inicio que ve cualquier visitante. No requiere cuenta. Explica qué es Lokro y tiene los botones de registro.

👤

Zona de Usuario

Mapa, búsqueda de profesionales, solicitar servicio, pagar, chat, tracking y perfil personal.

🔧

Zona de Prestador

Dashboard de solicitudes, agenda, ingresos, edición de perfil y portafolio.

🛡️

Zona de Admin

Panel para ver todos los usuarios, solicitudes y prestadores. Puede cambiar roles y cancelar servicios.

🔌

API interna (conectores)

Rutas internas que conectan con Mercado Pago (crear cobro, recibir confirmación de pago) y con Resend (enviar emails). El usuario nunca las ve directamente.

¿Cómo se protege cada zona?

Hay dos capas de protección que trabajan juntas:

🚦 Capa 1 — Middleware

Es el portero de la app. Antes de que cargue cualquier página, verifica si el usuario tiene sesión y si su rol le permite entrar. Si no tiene permiso, lo redirige.

🔒 Capa 2 — Seguridad en la base de datos (RLS)

Aunque alguien logre bypassear el middleware, la base de datos tiene sus propias reglas. Un usuario nunca puede ver los datos de otro usuario, sin importar qué.

Base de datos

¿Qué información guarda Lokro?

12 tablas que guardan todo lo que pasa en la plataforma

Tabla ¿Qué guarda?
users Todos los usuarios: nombre, email, rol (usuario / prestador / admin) y ubicación GPS
provider_profiles El perfil del prestador: descripción, tarifa por hora, calificación promedio, si está disponible
service_requests Cada solicitud de servicio: quién la pidió, a quién, qué necesita, dónde, cuándo y en qué estado está
messages Los mensajes del chat entre usuario y prestador
payments El pago de cada servicio: monto total, comisión de Lokro (10%) y lo que recibe el prestador
reviews Las calificaciones que se dejan usuario y prestador mutuamente al terminar
notifications Las notificaciones dentro de la app (nueva solicitud, pago recibido, etc.)
provider_locations La ubicación GPS del prestador actualizada en tiempo real durante el servicio
categories Las categorías de servicio: Plomería, Electricidad, Limpieza, Tutoría, etc.
Automatizaciones en la base de datos

Cuando alguien deja una calificación, la base de datos recalcula automáticamente el promedio del prestador sin que el código tenga que pedirlo. Cuando un usuario se registra, la base de datos crea su perfil automáticamente.

Flujos principales

¿Cómo funciona paso a paso?

Los recorridos más importantes dentro de la app

Flujo 1 — Registro e inicio de sesión

1
El usuario entra a la app y se registra Puede registrarse con email y contraseña, o con su cuenta de Google con un solo clic. Elige si quiere ser Usuario o Prestador.
2
La base de datos crea su perfil automáticamente Sin que nadie tenga que hacer nada manualmente, el sistema crea su ficha en la plataforma. Si es prestador, también crea su perfil vacío listo para completar.
3
La app lo redirige al lugar correcto Usuario → va al mapa de inicio. Prestador → va a completar su perfil. Admin → va al panel de control.

Flujo 2 — Solicitar un servicio (Usuario)

1
Busca en el mapa Ve un mapa con puntos que representan prestadores disponibles cerca de su ubicación. Puede filtrar por categoría, precio o calificación.
2
Revisa el perfil del prestador Antes de contratar, puede ver la descripción, fotos de trabajos anteriores, calificación y precio por hora.
3
Hace la solicitud Describe qué necesita, elige fecha y hora, y comparte su ubicación. La solicitud queda en estado "Pendiente".
4
El prestador acepta y el usuario paga Cuando el prestador acepta, el usuario recibe una notificación y pasa a pagar de forma segura con Mercado Pago. El dinero queda retenido hasta que el trabajo se complete.
5
Seguimiento en tiempo real El usuario puede ver en el mapa exactamente dónde está el prestador en camino, y chatear con él directamente.
6
Calificación mutua Al terminar, usuario y prestador se califican entre sí. El sistema actualiza automáticamente el promedio del prestador.

¿Por qué es seguro?

El dinero nunca lo toca Lokro directamente. Mercado Pago lo retiene y solo lo libera al prestador cuando el servicio se completa. Si hay un problema, el usuario puede reclamar el reembolso.

Tiempo real

¿Qué pasa al instante?

Tres cosas en la app se actualizan sin necesidad de recargar la página

💬

Chat

Los mensajes entre usuario y prestador aparecen al instante, como WhatsApp.

📍

Tracking GPS

El punto del prestador se mueve en el mapa del usuario mientras se acerca al domicilio.

🔔

Notificaciones

Cuando llega una nueva solicitud o hay una actualización, aparece el aviso sin recargar.

¿Cómo funciona técnicamente?

Supabase mantiene una conexión permanente entre el servidor y el navegador (WebSocket). Cuando algo cambia en la base de datos, el aviso llega al instante al dispositivo del usuario, como si fuera una app móvil nativa.

Decisiones clave

¿Por qué se eligió cada tecnología?

Las razones detrás de las herramientas usadas

Decisión ¿Por qué? Alternativa descartada
Next.js como base Permite que Google indexe la app (SEO) y que cargue rápido. Todo en un solo proyecto sin servidor separado. React puro (sin SEO), servidor Express aparte (más complejo)
Supabase como base de datos Incluye base de datos, login, archivos y tiempo real en un solo servicio. Ahorra mucho tiempo de desarrollo. Firebase (no tan potente), servidor propio (más costoso)
Mercado Pago Es el método de pago más usado en Colombia y Latinoamérica. Acepta PSE, efectivo y tarjetas locales. Stripe (mejor tecnología pero menos usuarios en Colombia)
Seguridad en la base de datos (RLS) Aunque haya un error en el código, la base de datos garantiza que ningún usuario vea datos de otro. Es una red de seguridad extra. Solo validar en el código (más frágil)
Mapbox para los mapas Mapas más personalizables y con mejor rendimiento que Google Maps para este caso de uso. Google Maps (más costoso a escala)
